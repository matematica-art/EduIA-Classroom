# Documento de Requerimientos
# Sistema EduIA Classroom

## 1. Introducción

EduIA Classroom es una plataforma educativa inteligente diseñada para gestionar procesos de enseñanza-aprendizaje mediante herramientas digitales e inteligencia artificial.

El sistema permitirá administrar cursos, contenidos educativos, actividades, evaluaciones y proporcionar apoyo personalizado mediante un tutor virtual basado en IA.

---

# 2. Objetivo del Sistema

Desarrollar una plataforma web educativa que facilite la interacción entre docentes y estudiantes, permitiendo gestionar actividades académicas y mejorar la experiencia de aprendizaje mediante tecnología e inteligencia artificial.

---

# 3. Alcance del Sistema

El sistema permitirá:

- Registrar usuarios.
- Administrar roles de usuario.
- Crear y gestionar cursos.
- Organizar contenidos educativos.
- Crear actividades académicas.
- Realizar evaluaciones.
- Gestionar calificaciones.
- Consultar progreso académico.
- Utilizar un asistente educativo con IA.

---

# 4. Usuarios del Sistema

## Administrador

Responsable de administrar la plataforma.

Funciones:

- Registrar usuarios.
- Gestionar permisos.
- Supervisar cursos.
- Consultar estadísticas.

---

## Docente

Responsable de administrar el proceso educativo.

Funciones:

- Crear cursos.
- Crear módulos de aprendizaje.
- Subir contenidos.
- Crear actividades.
- Crear evaluaciones.
- Revisar entregas.
- Registrar calificaciones.

---

## Estudiante

Usuario que participa en el proceso de aprendizaje.

Funciones:

- Acceder a cursos inscritos.
- Consultar contenidos.
- Entregar actividades.
- Realizar evaluaciones.
- Consultar notas.
- Utilizar el tutor IA.

---

# 5. Requerimientos Funcionales

## RF01 - Gestión de usuarios

El sistema debe permitir registrar usuarios con diferentes roles.

## RF02 - Inicio de sesión

El sistema debe permitir autenticación mediante usuario y contraseña.

## RF03 - Gestión de cursos

El docente debe poder crear, modificar y administrar cursos.

## RF04 - Gestión de contenidos

El docente debe poder agregar recursos educativos.

## RF05 - Gestión de actividades

El sistema debe permitir crear tareas y recibir entregas.

## RF06 - Evaluaciones

El sistema debe permitir crear cuestionarios y calcular resultados.

## RF07 - Calificaciones

El sistema debe almacenar y mostrar calificaciones.

## RF08 - Tutor IA

El sistema debe permitir interacción con un asistente inteligente para apoyar el aprendizaje.

---

# 6. Requerimientos No Funcionales

## Seguridad

- Proteger la información de usuarios.
- Controlar acceso según roles.

## Usabilidad

- La interfaz debe ser sencilla e intuitiva.

## Disponibilidad

- El sistema debe estar disponible para estudiantes y docentes.

## Compatibilidad

- Debe funcionar en computadoras, tablets y dispositivos móviles.

## Rendimiento

- Debe responder rápidamente a las solicitudes del usuario.
